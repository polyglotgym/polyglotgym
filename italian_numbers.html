How to Use This App

What this is

A drill for Italian number words. Italian is more compositional than Spanish — under one million, numbers are written as a single word (duemilacinquecentocinquantacinque), and the joining rules produce a specific set of traps worth drilling deliberately.

The deck is roughly 120 cards, covering 0–20, tens, hundreds, thousands, millions, and a set of representative composites and years.

Learn the patterns, then drill the traps.

The two directions
  • Number → Words (default) — you see the numeral and type the Italian words. This is production.
  • Words → Number — you see the Italian words and type the numeral. This is comprehension.

Both directions drill the same underlying cards. Progress is shared.

The Rules
0–20: base forms

Every number up to 20 is memorised. Note the dici- prefix for 17-19 (diciassette, diciotto, diciannove), not dieci-.

21–99: joined tens + units

Compound tens are written as one word: ventidue, trentacinque, quarantasette. Two rules for the tens boundary:

  • Drop the final vowel before uno and otto: venti → ventuno, ventotto. trenta → trentuno, trentotto.
  • Keep the final vowel before tré: trenta → trentatré (not "trentré"). venti → ventitré (keeps i because tré starts with a consonant cluster).
Hundreds: fully regular

Unlike Spanish, Italian hundreds are all regular: cento, duecento, trecento, quattrocento, cinquecento, seicento, settecento, ottocento, novecento.

One rule for cento + otto-family: cento drops its -o before otto and ottanta: centotto (108), centottanta (180). Also for the other hundreds: duecentotto, duecentottanta.

Thousands: mille and -mila

1000 is mille — not "un mille". Multiples take the -mila suffix joined to the multiplier: duemila, tremila, cinquemila, diecimila, ventunomila, centomila. Everything under one million is a single word.

Millions and billions

1,000,000 = un milione — "un", not "uno". 2,000,000 = due milioni (plural). Above one million, Italian uses spaces: due milioni cinquecentomila.

Truncation before milione/i and miliardo/i: ventuno → ventun (21 million = ventun milioni). But ventitré stays (23 million = ventitré milioni).

1,000,000,000 = un miliardo (10⁹). Italian bilione means 10¹² (rare).

Context-Dependent Forms

This app drills standalone forms. Two truncations apply only when a number precedes a noun:

  • uno → un before masculine singular noun: un libro.
  • uno → una before feminine singular noun: una sedia.

These belong to a sentence-context drill. This app drills standalone forms.

Suggested Workflow

Start with Standard only. Get the plain patterns automatic — 0–20, tens, hundreds, thousands — before touching the traps.

Then Tricky only. 22 cards. Run these as a dedicated session. This is where you internalise ventuno, ventotto, ventitré, trentatré, centotto, mille, ventunomila, un milione.

Then Years only. Optional. Years come with trivia for fun.

Switch direction. Once you can produce the words, drill Comprehension. The audio prompt (default on) trains you to hear numbers in the wild; the written prompt trains recognition.

The Traps

ventuno, not ventiuno. Drop final -i before uno.
ventotto, not ventiotto. Drop final -i before otto.
ventitré, with accent. tré keeps the accent in all compounds.
trentatré, not trentré. The -a of trenta is retained before tré.
centotto, not centootto. cento drops -o before otto.
mille, not un mille. No "un" before 1000.
duemila, not duemille. Mille becomes -mila in compounds.
un milione, not uno milione. uno truncates to un before milione.
ventun milioni, not ventuno milioni. uno truncates before milioni.
diciassette / diciotto / diciannove. dici- prefix, not dieci-.

Context-Dependent Forms

uno → un before masc. sg. noun (un libro); uno → una before fem. sg. noun (una sedia).
These are not drilled — this app drills the standalone forms.
