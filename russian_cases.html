How to Use This App

What this is

A high-intensity drill tool for one thing: Russian noun case forms. Six cases × two numbers × several noun types = a lot of endings, and getting them wrong is one of the loudest mistakes a learner can make.

This app drills the inflected forms — you see a base noun and a target case, you produce the form. It does not drill which case to use when; that's a separate skill (see the final note).

Think of this app as like a metronome for case endings.

The four piles
⚪ ActiveCards you're still working through. Appear in every drill. A card is Active if it's new or if you've failed it once and corrected it.
🟡 PendingCards you've recently missed. Mixed into the general rotation but called out separately so you can drill them deliberately. Pin with 📍 or 📌 All.
🔴 PinnedYour watchlist. Stays in rotation indefinitely. Auto-pin after 3 fails (adjustable). To retire one, correct it, then unpin.
💚 KnownMastered. Skipped in Adaptive mode. To review, switch to Full Sweep or Forget All.
How cards move between piles

Cards change state based on your first answer in each session:

FromCorrect (first attempt)Wrong
Active→ Known→ Pending
Pending→ Active→ Pending
Pinned→ Pinned (stays)→ Pinned (stays)
Known→ Known (stays)→ Pending (Sweep only)

If you fail a card and then get it right later in the same session, that later correct doesn't count for state changes — it's just practice.

Russian-Specific Behaviour
The Nom Sg quirk

Nominative Singular cards are special: they show the English meaning and ask you for the dictionary form. Showing the base word would give away the answer, since Nom Sg is the dictionary form. Every other card shows the base word and asks for the target case.

This means Nom Sg cards test recall + form; other cases test form only. That's deliberate — you shouldn't have to recall "table → стол" every time you want to drill "стол → стола".

Animate vs inanimate

The distinction only matters for masculine accusative (and by extension, all animate plurals). Inanimate masc Acc = Nom (стол → стол), but animate masc Acc = Gen (друг → друга). The app shows a warning banner on these cards.

Homograph warnings

Many case endings collide — стол is both Nom Sg and Acc Sg, for instance. When you get a form right, the app tells you which other cases share it. This is your cheat sheet for "why does my answer look like the same word?"

Cyrillic vs transliteration

Input accepts either. Typing стола or stola are both correct. ё is normalised to е automatically. The Script Display settings control how the base word appears in prompts — the answer feedback always shows both scripts.

The Settings
Adaptive vs Full Sweep

Adaptive (default) draws from Active + Pending + Pinned, skipping Known. Full Sweep draws from everything, useful for a check-up. Failing a Known card in Sweep demotes it back to Pending.

Production vs acoustic
  • Production Lane — you see the base word and target case, you type the inflected form.
  • Acoustic Lane — you hear the inflected form, you identify which case and number it is.

Acoustic mode is particularly valuable for Russian: many forms are ambiguous to see but the same form can be distinguished by context when heard. Play Mode lets you test without recording anything.

Hotkeys

Space or Enter for move on / correct, X (or 1) for incorrect, 2 for correct (honour mode), Ctrl+Z to undo the last answer.

Suggested Workflow

Beginners. Start with Nominative and Accusative only, singular only, and only Masculine Inanimate + Feminine. This is the smallest productive slice — subject + direct object sentences.

Add Genitive next. Genitive is the second most useful case (possession, negation, quantity). Concentrate on the -а/-я masc and -ы/-и fem patterns.

Add Dative, Instrumental, Prepositional. These round out the basic cases. Instrumental and Prepositional have some softer patterns; they'll take more practice.

Introduce Plural. Add plural one case at a time, starting with Nom Pl and Gen Pl. Gen Pl is the hardest — often the form is a "bare stem" with no ending at all.

Add harder noun types. Soft stems (-ь), sibilants (-ч/-ш/-ж/-щ), animate masculine (the Acc = Gen pattern), third-declension feminine.

Every third or fourth session. Hit Drill Pending in the Reviews tab. This is where you patch the holes.

When you're tired. Turn on 🎮 Play Mode. Nothing gets recorded.

Final Note

This app drills form production. It does not drill which case to use in a given sentence — that's a separate skill. You can conjugate perfectly and still pick the wrong case for a preposition, or miss that a verb governs an unexpected case. If you're at the stage where you know the endings but aren't sure when to use them, that gap deserves its own app (sentence-context drills with case selection from a prompt). This is a known limitation, not a bug.

Also not covered: adjective agreement (adjectives agree with nouns in case, number, gender — a whole other drill), participles, or irregular plurals beyond what's in the deck.
