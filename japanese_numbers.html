How to Use This App

A drill for reading, writing, and hearing Japanese numbers from 1 up to the 兆 scale (999,999,999,999). Not a course — a fast recall drill, in the same spirit as the rest of the suite.

The three directions
  • Read — you see a Japanese number, you type the English numeral.
  • Write — you see an English numeral, you produce the Japanese form.
  • Listen 🔊 — you hear the number, you type the English numeral. Ear training.
Range and deck size

The range selector (in Options) sets which numbers the deck can contain — from Basics (1–10) up to the 億 & 兆 scale. The deck-size selector caps how many appear in one session (default 15). Changing direction, range, style, or deck size starts a fresh session — worth knowing if you're mid-drill.

Production method and text style

Type (default) — you type the answer. Honour — you say it aloud, press Space to reveal, then self-mark. Text style only applies in Write mode: Rōmaji (sanju go), Kanji (三十五), or Mixed (Arabic digits + kanji unit markers, e.g. 3千5百4十1 for 3,541).

The session model

Each session is a fresh random deck. Wrong answers get pushed to the end so you see them again before the session ends. When the deck runs out, you can loop (Endless mode) or finish.

Unlike the verb and clitic apps in the suite, there is no graduated "known" pile here. Every session draws a fresh sample from the selected range. Your lifetime correct / total stats and your mistake log do persist, but individual cards aren't tracked between sessions. If you want to carry a specific set forward, use Recovery Codes in the Review tab.

Recovery codes

The Review tab has an export/import box. After a session, your mistakes are encoded as a compact string (e.g. 1234;5678;90). Copy that string, save it wherever you like, and later paste it back to drill that exact set again. Or press 🎯 Drill These Saved Errors Only to jump straight into a session with just those numbers.

Hotkeys

Space or Enter — start session, submit answer, or advance. 1 / X and 2 — mark wrong / correct in Honour mode. Ctrl+Z — undo the last answer.

Japanese Numbers — the 4-Digit Hurdle

English groups numbers in threes — thousands, millions, billions. Japanese groups in fours: man (万, 10,000), oku (億, 100,000,000), chō (兆, 1012).

This is the biggest single hurdle for English speakers. 100,000 is not "hundred thousand" — it's jū-man (十万), literally "ten man". 10,000,000 is issen-man (一千万), "one thousand man". Every number above 10,000 needs to be re-framed mentally as (how many man?) + (remainder under 10,000).

Drill this specifically. If you consistently miscount above 10,000, it's the 4-digit grouping not being automatic yet — worth its own focused session before pushing into larger ranges.

Basic Numbers Reference

This app drills yon (not shi) for 4, nana (not shichi) for 7, and kyū (not ku) for 9 — the common standalone counting forms.

• 300: san-byaku | 600: rop-pyaku | 800: hap-pyaku
• 3,000: san-zen | 8,000: has-sen

Large numbers: 100,000 is 十万 (jū-man, "ten man"), not "hundred thousand". 1,000,000 is 百万 (hyaku-man, "hundred man"). See "The 4-Digit Hurdle" above — this catches everyone.

Zero: 零 (rei) or 〇 (zero). In practice "ゼロ" (katakana, from English) is most common. Rare in this deck (range starts at 1) but worth knowing.

Typing tip: Macrons (ū, ō) are optional. Type sanju, sanjū, or sanjuu — all are accepted. Commas in English numerals are ignored (12,345 = 12345).
